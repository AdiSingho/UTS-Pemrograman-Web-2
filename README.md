Aplikasi To-Do List (UTS Pemrograman Web II)

Kode sumber aplikasi ini dibuat oleh Singgih Adi Nugroho 202359201011 pada 2026 untuk mengerjakan soal UTS Pemrograman Web II.

## Kebutuhan Fungsional yang Diselesaikan:
- Melihat daftar tugas
- Membuat tugas baru
- Menyelesaikan tugas
- Melihat tugas yang sudah selesai dalam jangka waktu tertentu
- Menghapus tugas yang belum diselesaikan
- Mengedit tugas yang belum diselesaikan
- Melihat laporan tugas harian
